# Workflows

This folder documents how information moves through the brain. The AI follows these files, so you can switch AI apps without losing your way of working.

Core workflows:

- `ingest-data.md`: capture raw information into `90-inbox/` by hand.
- `import-with-connectors.md`: let an AI app import from Gmail, Drive, or Calendar through its connectors.
- `process-inbox.md`: turn inbox items into structured knowledge.
- `summary-policy.md`: decide when generated summaries should exist.
- `daily-routine.md`: the full update, from import to saved result.
- `morning-brief.md`: an optional short message about what needs attention today.

Each workflow ends with an agent prompt that you can paste into your AI app.

When the AI makes the same mistake twice, add a rule to the right workflow. That is how the brain gets better.
