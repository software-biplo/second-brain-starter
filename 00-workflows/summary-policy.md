# Summary Policy

Generated summaries live in `99-generated/`.

They are useful views, not source truth.

## Always Generate

Generate and maintain summaries for:

- active clients
- active projects
- important business areas
- weekly business context
- global open loops

## Generate When Useful

Generate summaries when something is:

- large
- frequently referenced
- decision-heavy
- risk-heavy
- spread across many files
- asked about repeatedly

Examples:

- long email thread summary
- brand positioning summary
- sales pipeline summary
- project risk summary

## Do Not Generate

Avoid summaries for:

- tiny notes
- one-off emails
- stale inactive material
- trivial admin content

## Source Rule

If a generated summary is wrong, fix the original source file first, then regenerate the summary.
