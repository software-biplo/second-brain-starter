# Generated

This folder contains AI-generated summaries, dashboards, indexes, and rollups.

Generated files are derived views. They are useful for quick reading and retrieval, but they are not the source of truth.

- `project-summaries/`: one summary per project
- `area-summaries/`: one summary per area
- `client-briefs/`: one-page briefs per client, when useful
- `thread-summaries/`: summaries of long email threads
- `weekly/`: weekly overviews
- `business/`: analyses across the whole business
- `indexes/`: review queue and resource indexes

Project, area, and resource summaries are also written into their folders as `GENERATED.md`, so agents can discover context locally.

If a generated summary is wrong, correct the original source file first, then regenerate the summary.
