# Inbox

Everything new arrives here first. Do not think about the right folder while capturing.

- `emails/`: email threads
- `files/`: documents, PDFs, spreadsheets
- `meetings/`: calendar events and meeting notes
- `notes/`: quick notes, voice memo transcripts, exported chats
- `links/`: articles and links

The AI moves items into PARA with `00-workflows/process-inbox.md`. Unclear items stay here, marked `needs_review`.
